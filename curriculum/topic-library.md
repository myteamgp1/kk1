# Topic Library

Topic bank for daily assignments. When a topic arrives, check here first:
if it (or a neighbor) exists, reuse its patterns and follow the *Recycles from*
links so lessons build on each other. Add new topics as they get assigned —
this file grows with use.

Levels: **B** beginner · **HB** high-beginner · **I** intermediate
