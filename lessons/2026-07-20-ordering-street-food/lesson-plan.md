**Contingencies**
- Running long → cut production round 2 (Anna-as-vendor). NEVER cut the wrap-up.
- Running fast → extension: customer changes their order after hearing the price ("แพงไป… เอาข้าวผัดไก่ดีกว่า" — too expensive, I'll take chicken fried rice instead).

## Anticipated Chinese-L1 difficulties (this topic)

1. **Vowel length**: ข้าว khâao must stay long — Wei-Ting's known weak spot; drill เข้า khâo vs ข้าว khâao once in presentation.
2. **Final -t** in ผัด phàt / เผ็ด phèt: Mandarin speakers drop it or add a vowel; Anna's Cantonese 入聲 = free win, let her model it.
3. **Tone triple** ข้าว/ขาว/ข่าว: â and à will be read pinyin-style — point at the footer legend before Drill A.
4. **Rising tone** ǎ in หมู mǔu / ขอ khɔ̌ɔ: Anna's flattening issue — listen specifically.
5. **Cluster** in เปล่า bplàao (bpl-): both will insert a vowel ("bpə-làao") — model slow → fast.

## Answer key (handout exercises §5)

1. **ขอ**ผัดกะเพราไก่ครับ/ค่ะ
2. ขอข้าวผัดกุ้งครับ/ค่ะ ไม่เผ็ดครับ/ค่ะ
3. ทั้งหมด**เท่าไหร่**ครับ/คะ
4. Spice ladder order: ไม่เผ็ด → เผ็ดนิดหน่อย → เผ็ดมาก (not spicy → a little spicy → very spicy)
5. (live listening exercise — teacher says a random order, student writes dish + spice level)

## QA appendix (tone derivations, per reference/romanization.md §4)

- ข้าว: ข high + ้ → falling → khâao ✓ · ขาว: high, live → rising → khǎao ✓ · ข่าว: high + ่ → low → khàao ✓

- หมู: ห นำ ม → high-class, live → rising → mǔu ✓
- ผัด: ผ high, dead short → low → phàt ✓ · กะ: ก mid, dead short → low → gà ✓ · เพรา: พ low (พร cluster), live → mid → phrao ✓
- ไข่: ข high + ่ → low → khài ✓ · ดาว: ด mid, live → mid → daao ✓
- เผ็ด: ผ high, dead short → low → phèt ✓
- อร่อย: อ นำ ร (irregular set) → mid-class rules + ่ → low → à-rɔ̀ɔi ✓
- น้ำ: น low + ้ → high → náam ✓ (vowel irregularly long) · เปล่า: ป mid (ปล cluster) + ่ → low → bplàao ✓
- เอา: อ mid, live → mid → ao ✓ · ขอ: ข high, live → rising → khɔ̌ɔ ✓
- เท่า: ท low + ่ → falling → thâo ✓ · ไหร่: ห นำ ร + ่ → low → rài ✓
- ไม่: ม low + ่ → falling → mâi ✓ · นิด: น low, dead short → high → nít ✓ · หน่อย: ห นำ น + ่ → low → nɔ̀ɔi ✓ · มาก: ม low, dead long → falling → mâak ✓
- ใส่: ส high + ่ → low → sài ✓ · ด้วย: ด mid + ้ → falling → dûai ✓ · แล้ว: ล low + ้ → high → lɛ́ɛo ✓
