# Romanization Standard — Paiboon-style (single source of truth)

Every romanized Thai syllable in this workspace MUST follow this system.
When generating or reviewing material, **re-derive each syllable's tone from
its Thai spelling using §4** and check the diacritic matches. Never guess.

Why Paiboon-style and not RTGS: RTGS drops tones and vowel length entirely and
merges distinct vowels — useless for tonal-language learners. Our students are
mostly Chinese speakers who *can* hear and produce tones; the romanization must
show them.

---

## 1. Tone marks (the five tones)

| Tone | Mark | Example | Thai example |
|---|---|---|---|
| Mid (สามัญ) | unmarked `aa` | maa | มา (come) |
| Low (เอก) | grave `àa` | màak | หมาก (betel) |
| Falling (โท) | circumflex `âa` | mâak | มาก (very) |
| High (ตรี) | acute `áa` | máa | ม้า (horse) |
| Rising (จัตวา) | caron `ǎa` | mǎa | หมา (dog) |

### ⚠ The pinyin trap (tell every Chinese-speaking student, every course)

The diacritics LOOK like pinyin but two of them mean something different:

| Symbol | In pinyin | In Paiboon (here) | Conflict? |
|---|---|---|---|
| `ā` / unmarked | T1 high-level | **mid tone** | close enough |
| `á` | T2 **rising** | **HIGH tone** | ⚠ YES |
| `ǎ` | T3 dipping-rising | **rising tone** | compatible |
| `à` | T4 **falling** | **LOW tone** | ⚠ YES |
| `â` | (unused) | **falling tone** | new symbol |

Rule of thumb for students: *"the hat falls (â), the accent flies high (á),
the grave stays low (à), the check bounces up (ǎ)."*

## 2. Consonants (initial position)

Unaspirated stops are written like pinyin's "voiced-looking" letters — this is
deliberate and maps perfectly onto pinyin habits (pinyin b/d/g are unaspirated,
p/t/k aspirated):

| Thai | Roman | Sound hint (pinyin anchor) |
|---|---|---|
| ก | g | unaspirated k — pinyin **g** (哥) |
| ข ฃ ค ฅ ฆ | kh | aspirated — pinyin **k** (科) |
| ง | ng | as in si**ng**; can start a syllable (งู nguu) |
| จ | j | unaspirated ch — pinyin **z/j**-ish (机) |
| ฉ ช ฌ | ch | aspirated — pinyin **q/ch** (七) |
| ซ ศ ษ ส | s | s |
| ญ ย | y | y |
| ด ฎ | d | true voiced d |
| ต ฏ | dt | unaspirated t — pinyin **d** (打) |
| ถ ท ฑ ฒ ธ | th | aspirated — pinyin **t** (他) |
| น ณ | n | n |
| บ | b | true voiced b |
| ป | bp | unaspirated p — pinyin **b** (爸) |
| ผ พ ภ | ph | aspirated — pinyin **p** (怕) |
| ฝ ฟ | f | f |
| ม | m | m |
| ร | r | tapped/trilled r (colloquially becomes l) |
| ล ฬ | l | l |
| ว | w | w |
| ห ฮ | h | h |
| อ | (silent) | vowel carrier / glottal stop |

**Never write** `kh` as `k`, `ph` as `p`, or `th` as `t` — the h marks
aspiration and is not optional. `ph` is NEVER an f-sound (ภูเก็ต = phuu-gèt).

### Final consonants

Only these sounds occur at syllable end:

| Sound | Roman | From Thai letters |
|---|---|---|
| -p (unreleased) | p | บ ป พ ฟ ภ |
| -t (unreleased) | t | ด ต ถ ท ธ จ ช ซ ศ ษ ส ฎ ฏ ฐ ฑ ฒ |
| -k (unreleased) | k | ก ข ค ฆ |
| -m | m | ม |
| -n | n | น ณ ญ ร ล ฬ |
| -ng | ng | ง |
| -i glide | i | ย (e.g. ไทย thai) |
| -o glide | o | ว (e.g. แมว mɛɛo) |

## 3. Vowels

Length matters: short = single letter, long = doubled letter.

| Thai (with อ) | Short | Thai | Long | Sound hint |
|---|---|---|---|---|
| อะ / อั- | a | อา | aa | father |
| อิ | i | อี | ii | see |
| อึ | ʉ | อือ | ʉʉ | unrounded u — say "u" while smiling (no English/Mandarin equivalent) |
| อุ | u | อู | uu | boot |
| เอะ | e | เอ | ee | pay (no glide) |
| แอะ | ɛ | แอ | ɛɛ | cat |
| โอะ | o | โอ | oo | go (no glide) |
| เอาะ | ɔ | ออ | ɔɔ | law |
| เออะ | ə | เออ | əə | ago / 呃 |
| อัวะ | ua | อัว | uua | ตัว dtuua |
| เอียะ | ia | เอีย | iia | เมีย miia |
| เอือะ | ʉa | เอือ | ʉʉa | เมื่อ mʉ̂ʉa |

Diphthongs / specials:

| Thai | Roman | Example |
|---|---|---|
| ไอ ใอ อัย | ai | ไป bpai |
| อาย | aai | สาย sǎai |
| เอา | ao | เอา ao |
| อาว | aao | ข้าว khâao |
| อำ | am | น้ำ náam (irregular: pronounced long) |
| อิว | iu | หิว hǐu |
| เอ็ว / เอว | eo / eeo | เร็ว reo |
| แอว | ɛɛo | แมว mɛɛo |
| เอียว | iao | เดี๋ยว dǐao |
| อุย | ui | คุย khui |
| โอย / ออย | ooi / ɔɔi | อร่อย à-rɔ̀i |
| เอย | əəi | เลย ləəi |
| อวย | uai | ช่วย chûai |

Tone marks go on the (first letter of the) stressed vowel: `khâao`, `mʉ̂ʉa`, `dǐao`.

## 4. Tone-derivation cheat sheet (use this to VERIFY every syllable)

### Step 1 — consonant class of the initial

- **Mid (กลาง):** ก จ ฎ ฏ ด ต บ ป อ
- **High (สูง):** ข ฃ ฉ ฐ ถ ผ ฝ ศ ษ ส ห
- **Low (ต่ำ):** ค ฅ ฆ ง ช ซ ฌ ญ ฑ ฒ ณ ท ธ น พ ฟ ภ ม ย ร ล ว ฬ ฮ

Leading-letter overrides: **ห นำ** (หม หน หง หย หร หล หว …) → treat the
cluster as HIGH class (หมา mǎa). **อ นำ** (only อย่า อยู่ อย่าง อยาก) → treat
as MID class. In clusters like กร- ปล- ขล-, the class comes from the FIRST
letter (กล้วย = mid class → glûai).

### Step 2 — live or dead syllable?

- **Live (คำเป็น):** ends in a long vowel, -m, -n, -ng, -i, -o, or in am/ai/ao
- **Dead (คำตาย):** ends in a short vowel or a stop -p, -t, -k

### Step 3 — look up

**No tone mark:**

| Class | Live | Dead (short V) | Dead (long V) |
|---|---|---|---|
| Mid | mid | low | low |
| High | rising | low | low |
| Low | mid | **high** | **falling** |

**With tone mark:**

| Class | ่ (èek) | ้ (thoo) | ๊ (dtrii) | ๋ (jàt-dtà-waa) |
|---|---|---|---|---|
| Mid | low | falling | high | rising |
| High | low | falling | — | — |
| Low | **falling** | **high** | — | — |

(Low-class letters shift one step: mark ่ gives falling, mark ้ gives high.)

### Worked examples (the pattern every QA pass must follow)

- ข้าว: ข = high class, ้ mark → falling → **khâao** ✓
- ขาว: ข = high, no mark, live (long aa + o glide) → rising → **khǎao** ✓
- ข่าว: ข = high, ่ mark → low → **khàao** ✓
- น้ำ: น = low, ้ mark → high → **náam** ✓ (vowel irregularly long)
- หมู: ห นำ → high class, no mark, live → rising → **mǔu** ✓
- เผ็ด: ผ = high, no mark, dead (-t) → low → **phèt** ✓
- ม้า: ม = low, ้ mark → high → **máa** ✓
- อยาก: อ นำ → mid class, no mark, dead long → low → **yàak** ✓

## 5. Formatting conventions

- Thai script always appears FIRST and visually dominant; romanization is scaffolding below/beside it.
- Multi-syllable words: hyphenate syllables (à-rɔ̀i, thâo-rài, gà-prao).
- Polite particles: ครับ khráp / ค่ะ khâ / คะ khá — always show both in dialogues.
- Unwritten inherent vowels are romanized as pronounced: ถนน thà-nǒn.
- Irregular pronunciations follow SOUND, not spelling (น้ำ náam not nám, ไทย thai).
