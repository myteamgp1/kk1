# 🇹🇭 ระบบบทเรียนภาษาไทยรายวัน (Thai Daily Lesson System)

ระบบ AI Agents ที่ผลิตบทเรียนภาษาไทยสำหรับนักเรียนต่างชาติโดยอัตโนมัติทุกวัน และเตรียมอีเมลติดตามผลให้นักเรียนทุกเย็น

## ระบบทำอะไรบ้าง

**ทุกเช้า 06:00 น. (เวลาไทย)** — Routine "Daily Thai Lesson" จะ:
1. 🎯 **topic-scout** เลือกหัวข้อใหม่จากคลัง `data/topics.md` (ไม่ซ้ำของเดิม ไล่ระดับง่าย→ยาก)
2. 🔍 **thai-researcher** รีเสิร์ชหัวข้อจากเว็บแบบละเอียด พร้อมแหล่งอ้างอิง → `research.md`
3. ✍️ **lesson-writer** เขียนบทเรียนละเอียด 4 ภาษา: อังกฤษ, จีนตัวย่อ, จีนฮ่องกง, จีนไต้หวัน (แยกส่วนนักเรียนใหม่/เก่า)
4. 📚 **curriculum-producer** สร้างคู่มือการสอนแบบเต็ม + แผนภาพ SVG + แบบฝึกหัดพร้อมเฉลย
5. 💾 เก็บทุกอย่างใน `lessons/YYYY-MM-DD-<หัวข้อ>/` แล้ว commit + push

**ทุกเย็น 19:00 น. (เวลาไทย)** — Routine "Evening Follow-up Emails" จะ:
1. อ่านบทเรียนวันนี้ + รายชื่อนักเรียนใน `data/students.csv`
2. เขียนอีเมลติดตามผล **รายคน ในภาษาของนักเรียนคนนั้น** (นักเรียนใหม่/เก่าได้เนื้อหาต่างกัน)
3. สร้างเป็น **ฉบับร่างใน Gmail** ของคุณ → คุณเปิด Gmail ตรวจ แล้วกดส่งเอง
4. ถ้าเชื่อม Gmail ไม่ได้ อีเมลจะถูกบันทึกไว้ที่ `lessons/<วันที่>/emails/` แทน — เปิด Claude session แล้วพิมพ์ `/send-followup` เพื่อสร้าง draft ได้

## สิ่งที่คุณ (ครู) ต้องทำ

1. **แก้รายชื่อนักเรียนจริง** ใน [`data/students.csv`](data/students.csv) — ตอนนี้เป็นข้อมูลตัวอย่าง
   ```csv
   name,email,language,status,start_date,notes
   ชื่อนักเรียน,email@จริง.com,en|zh-CN|zh-HK|zh-TW,new|returning,YYYY-MM-DD,โน้ตเพิ่มเติม
   ```
2. **ทุกเย็น** เปิด Gmail → โฟลเดอร์ Drafts → ตรวจอีเมล → กดส่ง
3. **อยากเพิ่ม/แก้หัวข้อ** แก้ได้ที่ [`data/topics.md`](data/topics.md)
4. **อยากสั่งรันเองทันที** เปิด Claude Code session ในรีโปนี้ แล้วพิมพ์ `/daily-lesson` หรือ `/send-followup`

## โครงสร้างข้อมูลที่เก็บไว้

```
lessons/2026-07-20-thai-greetings/
├── research.md          ← ผลรีเสิร์ช + แหล่งอ้างอิง
├── lesson.en.md         ← บทเรียนภาษาอังกฤษ
├── lesson.zh-CN.md      ← 简体中文（中国大陆）
├── lesson.zh-HK.md      ← 繁體中文（香港，配廣東話對照）
├── lesson.zh-TW.md      ← 繁體中文（台灣）
├── teacher-guide.md     ← คู่มือการสอนแบบเต็ม (แผน 60 นาที กิจกรรม การประเมิน)
├── images/              ← แผนภาพ SVG (แผนภูมิวรรณยุกต์ บัตรคำ แผนผังบทสนทนา)
└── emails/              ← สำเนาอีเมลติดตามผลรายคน
```

ทุกอย่างถูกเก็บถาวรใน git — ดูประวัติบทเรียนทั้งหมดย้อนหลังได้ตลอด
