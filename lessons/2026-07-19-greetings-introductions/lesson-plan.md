## Anticipated Chinese-L1 difficulties

1. Pinyin trap on the handout diacritics (both students read pinyin natively) — hit hard in minute 1. **Confirmed: Wei-Ting fell into it anyway (dìi for dii).**
2. Rising tone on ไหม mǎi flattens (Cantonese speakers) — **confirmed with Anna.**
3. ครับ/ค่ะ has no Chinese analogue → habit-formation, expect weeks of prompting.

## QA appendix (tone derivations)

- สวัสดี: ส นำ ว → high-class rules, dead short → sà; wàt; ดี mid live → dii ✓
- ครับ: ค low, dead short → high → khráp ✓
- ค่ะ: ค low + ่ → falling → khâ ✓ · คะ: low, dead short → high → khá ✓
- ผม: ผ high, live → rising → phǒm ✓ · ฉัน: ฉ high, live → rising → chǎn ✓
- ชื่อ: ช low + ่ → falling → chʉ̂ʉ ✓ · คุณ: ค low, live → mid → khun ✓
- สบายดีไหม: sà (high, dead short → low) · baai (mid, live → mid) · dii (mid) · ไหม ห-นำ → rising mǎi ✓ (colloquially rises to mái — mention, don't test)
- ยินดีที่ได้รู้จัก: yin (low, live → mid) · dii · thîi (ท low + ่ → falling) · dâai (ด mid + ้ → falling) · rúu (ร low + ้ → high) · jàk (จ mid, dead short → low) ✓
- ขอบคุณ: ขอบ ข high, dead long → low → khɔ̀ɔp · khun ✓
- มาจาก: maa (low, live → mid) · jàak (mid, dead long → low) ✓
